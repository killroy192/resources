There is a bug to fix. Do not fix the bug, propose a solution, modify files, write code, or provide implementation steps.
Your task is context inspection only.

Inspect the available resources and produce a **context map** that identifies what information is relevant to understanding the bug/feature. Your output must describe the context you found, not what should be changed.

## Objective

Build a context map using these three layers:

### Hot context — directly required to understand the feature right now

Include:

* Current specification and/or implementation plan
* Active files directly involved
* Relevant logs, errors, screenshots, or reproduction evidence
* Explicitly stated requirements or acceptance criteria

### Warm context — reusable guidance that constrains or explains the feature

Include:

* `AGENTS.md`, repository rules, skills, and instructions
* Team/project conventions
* Relevant ADRs or architectural decisions
* Known constraints, assumptions, dependencies, or invariants

### Cold context — potentially useful background; investigate only when necessary

Include:

* Relevant repository areas
* Technical documentation
* Past PRs/commits
* Monitoring, historical logs, or incident records
* Related story/issue tickets

### Resources to ignore

Do not inspect or include:

* Deprecated documentation
* Generated files
* Vendored/third-party code unless directly required
* Unrelated modules
* Context with no plausible connection to the feature or bug

## Strict boundaries

You MUST NOT:

* Diagnose or explain the root cause
* Suggest a fix or workaround
* Propose code changes
* Modify any files
* Generate code, patches, diffs, or commands intended to fix the bug
* Produce an implementation plan
* Recommend which approach to take
* Infer missing requirements as facts
* Continue investigating merely to find a solution

You MAY:

* Read and inspect resources
* Trace references between resources
* Identify relevant files and dependencies
* Summarize existing requirements, decisions, constraints, and evidence
* Flag contradictions, gaps, or missing context **without resolving them**
* State that a resource appears relevant or irrelevant
